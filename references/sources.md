# Source register

Research for this skill: 2026-11-18. Weight sources by type: peer-reviewed and standards > manufacturer data (claims under stated conditions) > trade guides > practitioner reports. Standards are cited by scope; their clauses are not reproduced. Re-check current editions before using any value for a decision. Add new sources with the next ID.
